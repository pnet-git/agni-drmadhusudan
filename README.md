# Agni drops landing page, Dr. Madhu Sudan

Replica of the Kamdev Modak page for the new Ayurvedic weight loss drops. Target address: agni.drmadhusudan.com (not attached yet).

Build: `python3 build/build.py` assembles `index.html` from the Modak CSS (sibling folder `../modak`) plus `build/body.html`, `build/extra.css`, `build/script.js`. Edit the build files, never `index.html` by hand.

Placeholders that must be replaced before go-live: see `images/SOURCES.md`, the SAMPLE testimonial cards, the herb list and dose, the bottle picture, the Razorpay links and Kit form id in `build/script.js`.
